About Plant Care AI

Project Overview

Patho Plant is an intelligent web-based system designed to detect crop diseases from plant leaf images using advanced deep learning techniques. The goal of this project is to help farmers, researchers, and agricultural professionals identify plant diseases quickly and accurately. By simply uploading an image of a plant leaf, the system analyzes the image using a hybrid deep learning architecture and predicts whether the crop contains a disease or is healthy. The system achieves an accuracy of approximately 90% using a hybrid deep learning model combining Swin Transformer and Vision Transformer architectures.

Algorithms Used

🌿 Swin Transformer

Our project focuses on developing an intelligent image analysis system using advanced deep learning techniques. We utilize the Swin Transformer, a modern vision-based transformer model designed for efficient and accurate image understanding. Unlike traditional models, the Swin Transformer processes images by dividing them into smaller windows and analyzing them through a shifted window mechanism, allowing the system to capture both local and global visual features.

The goal of this project is to demonstrate how transformer-based deep learning models can enhance image processing applications and contribute to the development of smarter AI-driven solutions.

🧠 Vision Transformer (ViT)

In addition to the Swin Transformer architecture, our project also incorporates the Vision Transformer to further enhance the system’s ability to understand complex visual patterns. The Vision Transformer divides an input image into smaller patches and processes them using a self-attention mechanism, allowing the model to learn relationships between different regions of the image.

By combining the strengths of the Vision Transformer with the hierarchical structure of the Swin Transformer, our hybrid model improves feature extraction and overall image understanding. While the Swin Transformer efficiently captures local spatial features through its shifted window mechanism, the Vision Transformer focuses on capturing global relationships across the entire image.

🔥 Grad-CAM

To improve the interpretability of our deep learning model, our project utilizes Grad-CAM, a visualization technique used in deep learning models. Grad-CAM helps highlight the important regions of an image that influence the model’s prediction.

In our hybrid architecture that combines the Swin Transformer and Vision Transformer, Grad-CAM is applied to generate visual heatmaps over input images. These heatmaps show which parts of the image the model focuses on while making predictions.

By visualizing these attention regions, Grad-CAM improves transparency and helps users understand how the model makes decisions. This feature is particularly useful for analyzing model behavior, validating predictions, and ensuring reliability in image-based AI applications.
